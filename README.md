# 📚 Capítulo — Spring Boot + MongoDB

Projeto desenvolvido durante os estudos de **Spring Boot com MongoDB**, utilizando uma API REST para gerenciamento de usuários e posts.

---

## 🎯 Objetivo

Neste capítulo foi desenvolvido um backend utilizando:

- Java
- Spring Boot
- Spring Data MongoDB
- MongoDB
- MongoDB Compass
- Postman

O objetivo principal foi compreender como trabalhar com um banco de dados **NoSQL (MongoDB)** em uma aplicação Spring Boot.

---

## 🛠️ Tecnologias

| Tecnologia | Utilização |
|---|---|
| ☕ Java | Linguagem de programação |
| 🌱 Spring Boot | Desenvolvimento da API |
| 🍃 Spring Data MongoDB | Integração com MongoDB |
| 🍃 MongoDB | Banco de dados NoSQL |
| 🔍 MongoDB Compass | Visualização dos documentos |
| 🧪 Postman | Testes da API |
| 📦 Maven | Gerenciamento do projeto |
| 💻 IntelliJ IDEA | IDE utilizada |
